How to export a CSV from YouTube Studio
  1. Open YouTube Studio and select Analytics or Insights.
  2. Open the report you want and click Advanced Mode or See more.
  3. Set your date range. For video comparisons, use the content breakdown and include views, watch time, subscribers, and thumbnail metrics.
  4. Choose Export current view and select CSV. Unzip the download if needed, then import Table data.csv for video metrics and Totals.csv for daily views.

For a retention curve, import a separate CSV with Timestamp and Audience retention (%) columns. YouTube’s Advanced Mode guide
